## 4. 资金对账恒等式（每日 04:30 与手动触发）

| # | 恒等式 | 结果 |
|---|--------|------|
| 1 | 平台账户 `escrow_total` ≡ Σ流水（type=escrow, status=escrowed） | ✅ |
| 2 | Σ结算 + Σ退款 ≤ Σ托管入账（Σpay） | ✅ |
| 3 | Σ结算 − Σ已出账提现 − Σ冻结提现 ≡ Σ用户可提现余额 | ✅ |

> 恒等式 3 的口径说明：驳回提现会把「提现扣减」流水置为已退回并新增「提现退回」流水，
> 二者相互抵消，因此余额 = Σ结算 − Σ冻结 − Σ已出账。
